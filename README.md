# iphone-safari-check

A test page for how iPhone Safari draws code fonts, and a workflow that opens it on an iPhone simulator and saves a screenshot.

`page/index.html` shows the same code twice: once with `font-family: monospace` and once with `ui-monospace, 'SF Mono', Menlo, monospace`.

To run it: Actions, Check, Run workflow. Each Mac image saves a `result-…` file with the screenshot and log.
